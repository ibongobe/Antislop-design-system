# Anti-Slop DS

> Создай свою дизайн-систему и избавься от нейрослопа в проектах, которые делаешь с AI-агентами.

## Проблема

Ты делаешь сайт или кабинет с AI-агентами. Получается нейрослоп: разные цвета на разных экранах, случайные радиусы, «No data» вместо empty state, кнопки разного размера, тексты в разном стиле.

Обычные антислоп-фильтры убирают самые вопиющие признаки, но агент всё равно продолжает придумывать свои решения.

## Решение

Anti-Slop DS даёт агенту **источник правды** — твою дизайн-систему в YAML. Агент обязан брать решения только оттуда. Если чего-то нет — он останавливается и спрашивает, а не придумывает.

## End-to-end процесс

1. У тебя есть продукт / сайт, который ты делаешь с AI-агентами, и получается нейрослоп.
2. Ты спрашиваешь агента: «Как убрать нейрослоп из интерфейса?»
3. Агент даёт тебе ссылку на этот репозиторий.
4. Ты ставишь Anti-Slop DS одной командой в любой AI-агент.
5. Агент проводит короткий онбординг и собирает твою дизайн-систему.
6. Дальше все экраны строятся только из этой системы. Нейрослоп исчезает.

## Установка

```bash
# В любой AI-агент (Claude Code, Cursor, Codex, Cline и др.)
npx skills add ibongobe/Antislop-design-system
```

Или скопируй папку `skills/anti-slop-ds` в `.claude/skills/` / `.cursor/skills/` и т.д.

## Что внутри

| Файл / папка | Назначение |
|--------------|------------|
| `skills/anti-slop-ds/SKILL.md` | Инструкция для агента |
| `templates/` | Разбитые YAML-файлы (источник правды) |
| `docs/ONBOARDING.md` | Пошаговый онбординг |
| `docs/INPUT.md` | Что нужно дать на вход |
| `docs/DESIGN-RULES.md` | Жёсткие правила поведения агента |

## Как это работает

1. Агент читает `DESIGN-RULES.md` и шаблоны из `templates/`.
2. Проводит онбординг (или берёт базовый шаблон, если вход пустой).
3. Создаёт в твоём проекте:
   - `design-system/tokens.yaml`
   - `design-system/components.yaml`
   - `design-system/patterns.yaml`
   - `design-system/rules.yaml`
   - `design-system/voice.yaml`
   - `DESIGN-RULES.md`
4. Дальше при любой генерации UI берёт только оттуда.
